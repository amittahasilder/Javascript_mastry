PART 1: 50 JavaScript Function Interview Questions (With Short Answers)
🔹 Basics (1–10)

What is a function in JavaScript?
→ A reusable block of code that performs a task.

How do you declare a function?
→ function myFunc() {}

What is a function call?
→ Executing a function using ().

What is a parameter?
→ Variable listed in function definition.

What is an argument?
→ Value passed to a function.

What does a function return by default?
→ undefined

What is return used for?
→ To send value back from function.

Can a function return multiple values?
→ Yes, using array or object.

Difference between return and console.log()?
→ return gives value, console.log() prints.

Can functions be nested?
→ Yes.

🔹 Types of Functions (11–20)

What is function declaration?
→ function test(){}

What is function expression?
→ const test = function(){}

Difference between declaration & expression?
→ Hoisting.

What is arrow function?
→ Short syntax: () => {}

Do arrow functions have their own this?
→ No.

What is anonymous function?
→ Function without name.

What is IIFE?
→ Immediately Invoked Function Expression.

What is callback function?
→ Function passed as argument.

What is higher-order function?
→ Takes or returns function.

Can a function be stored in variable?
→ Yes.

🔹 Scope & Hoisting (21–30)

What is local scope?
→ Variables inside function.

What is global scope?
→ Variables outside functions.

What is lexical scope?
→ Scope defined by code position.

Are functions hoisted?
→ Function declarations are hoisted.

Are arrow functions hoisted?
→ No.

What is closure?
→ Function remembering outer scope.

Why closures are useful?
→ Data privacy.

Can inner function access outer variable?
→ Yes.

Can outer function access inner variable?
→ No.

What happens if function name matches variable name?
→ Variable overrides function.
